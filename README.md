## 📦 Como executar

1. Clone ou baixe este repositório.
2. Abra a pasta `projetos/portfolio-grid-bootstrap` no VS Code.
3. Execute `index.html` com o Live Server.
4. Mantenha a internet ativa para carregar as bibliotecas externas.
